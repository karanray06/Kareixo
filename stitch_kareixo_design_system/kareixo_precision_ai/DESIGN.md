## Brand & Style

This design system delivers a developer-first, minimal, precision-engineered aesthetic built for mission-critical code intelligence and automated review infrastructure. Inspired by craft-centric tools like Linear, Vercel, and GitHub’s modern design architecture, the system projects quiet authority, surgical clarity, and structural balance rather than marketing hyperbole.

### Design Movements & Tone
- **Technical Minimalism:** Heavy negative space, strict alignment grids, and intentional typography replace decorative clutter. 
- **Chassis Precision:** Visual hierarchy is anchored through crisp 1px borders, subtle tonal layering between paper canvas and card elevations, and exact vertical rhythm.
- **Controlled Intelligence:** Sourced directly from the robotic cat mascot and brand mark, an electric violet accent (`#8B5CF6`) is deployed exclusively as a signal of active machine intelligence, automated review findings, and runtime failover routing. The remainder of the chassis remains strictly monochrome and utilitarian.

### Emotional Target
The interface functions as a finely tuned instrument—a trustworthy "glass box" that feels native to high-performance terminal windows, pull request inspectors, and diagnostic tracing suites.

## Colors

The color palette is split into a primary neutral chassis and strict semantic channels. Light mode default defaults to an editorial off-white paper canvas (`#FAFAF9`), relieving the sterile glare of pure white.

### Application Rules
- **Chassis Neutrals:** Surfaces elevate via tone (`#FAFAF9` canvas to `#FFFFFF` card surfaces) and discrete structural dividing lines (`#E7E5E4`). Dark mode adopts an ink-deep volcanic ground (`#09090B`) with `#111113` surface containers.
- **Brand Violet (`#8B5CF6`):** Reserved strictly for AI actions, multi-model router failover pills, and logo accents. It must never be used for standard system links, destructive states, or general navigation triggers.
- **Code Review Semantics:** Chromatic hues are locked to Git and compiler feedback:
  - `--success` (`#16A34A`): Passed automated checks and clean diff additions (`+`).
  - `--warning` (`#D97706`): Non-fatal findings, performance alerts, and suggested optimizations.
  - `--error` (`#DC2626`): Breaking changes, syntax bugs, security vulnerabilities, and diff deletions (`-`).
  - `--info` (`#2563EB`): Active webhook transmissions and queued review tasks.

## Typography

The type system is calibrated around two distinct type classifications:
1. **Primary Interface:** `Geist` drives all narrative, navigational, and section headlines with tight letter spacing and proportional neutral structure.
2. **Technical Telemetry:** `JetBrains Mono` handles all stack traces, unified git diff hunk headers, model latency badges, and commit hashes.

### Rules of Engagement
- **Tight Headings:** High-level headers must retain tight negative tracking (`-0.03em` on display, `-0.02em` on section heads) to maintain modern editorial tension.
- **Rhythmic Diff Alignment:** Line heights within code diff components (`code-diff` and `code-gutter`) are matched to an exact 20px baseline to maintain gutter-to-content parity across multi-split screens.

## Layout & Spacing

Layout geometry follows an 8px base modular rhythm. Layouts conform to a 12-column fluid grid bound inside a strict `1280px` maximum viewport container.

### Breakpoints & Adaptations
- **Mobile (<640px):** Layout collapses to a single stacked column with `20px` margins. Code comparison views drop split views in favor of unified inline diff blocks. Major section spacing scales down to `72px`.
- **Tablet (640px – 1024px):** 6-column structures with `24px` gutters. Sidebars collapse into drawer sheets or top toolbars. Section margins compress to `96px`.
- **Desktop (1024px+):** Full 12-column grid. Diagnostic tools switch into two-column or multi-pane views (e.g., repository tree 240px fixed width, main inspection canvas flex-1). Section padding reaches `128px` to provide breathing room.

## Elevation & Depth

Visual hierarchy is communicated through structural lines and tonal shifts rather than heavy drop shadows.

### Elevation Layers
- **Base Canvas:** The page ground (`#FAFAF9` in light mode, `#09090B` in dark mode).
- **Surface Layer:** Card containers and diff viewers sit directly above the canvas with a `#FFFFFF` or `#111113` background, framed with a 1px border (`#E7E5E4` / `#27272A`).
- **Floating Overlays & Popovers:** Dropdowns, dialogs, and sticky headers use minimal, diffused ambient shadows (`0 8px 30px rgba(0, 0, 0, 0.05)`) paired with a frosted glass backdrop filter (`backdrop-filter: blur(12px)` at 90% opacity).

Heavy box shadows, layered skeuomorphic bevels, and artificial purple neon glows around whole containers are prohibited.

## Shapes

The design system maintains a balanced, structured shape profile:
- **Interactive Controls:** Buttons, text input fields, select triggers, and icon buttons strictly utilize `8px` corner radius.
- **Containers & Panels:** Standard cards, diagnostic frame panels, and code diff viewports adopt `12px` corner radius. Major landing feature units scale to `16px`.
- **Restricted Pills:** Full pill rounding (`9999px`) is strictly forbidden on primary buttons, cards, and inputs. It is sequestered solely to semantic status chips, telemetry badges, and small repository branch tags.

## Components

### Buttons
- **Primary:** Solid `#18181B` fill, `#FFFFFF` text, `8px` radius, `40px` height (`0 18px` horizontal padding). Transitions `150ms ease-out` with subtle `translateY(-1px)`.
- **AI Action Button:** Solid `#8B5CF6` fill with `#FFFFFF` text, or neutral solid `#18181B` with a subtle 1px violet rim (`#8B5CF6`) and an AI mascot sparkle icon.
- **Secondary / Outlined:** `#FFFFFF` background, `1px solid #E4E4E7`, `#18181B` text. Hover shifts border to `#D6D3D1` and background to `#F5F5F4`.
- **Ghost:** Transparent background, `#71717A` text, shifts to `#18181B` with `#F5F5F4` background on hover.

### Badges & Severity Chips
- **Geometry:** Height `24px`, pill-shaped (`9999px`), `JetBrains Mono` 12px font, with a leading 6px circular dot indicator.
- **Critical Error:** Background `#FEE2E2`, border `#FECACA`, text `#DC2626`.
- **Review Finding / Warning:** Background `#FEF3C7`, border `#FDE68A`, text `#D97706`.
- **AI / Router Engine:** Background `#F5F3FF`, border `#DDD6FE`, text `#7C3AED` with optional pulsing violet dot indicator.
- **Clean / Passed Check:** Background `#DCFCE7`, border `#BBF7D0`, text `#16A34A`.

### Code Diff Viewer
- **Container:** Framed inside `1px solid #E7E5E4` with `12px` rounded corners.
- **Header:** Background `#F5F5F4`, featuring file path in `JetBrains Mono` 13px bold, commit SHA, and change counter (`+24 -8`).
- **Diff Lines:** Monospace text in 13px/20px. Added lines receive `rgba(22, 163, 74, 0.08)` fill with `+` indicator in `#16A34A`. Deleted lines receive `rgba(220, 38, 38, 0.08)` fill with `-` indicator in `#DC2626`.
- **Inline Bot Comment:** Indented comment block directly below targeted lines. Framed with `8px` radius, crisp `3px solid #8B5CF6` left accent border, and bot avatar with "Apply Suggestion" button.

### Form Inputs & Textareas
- **Default State:** Background `#FFFFFF` (dark: `#111113`), `1px solid #E7E5E4`, radius `8px`, internal padding `10px 14px`, text `#18181B`.
- **Focus State:** 1px ring shift to `#18181B` (or `#8B5CF6` when targeting an AI prompt field). No blurred or colored drop shadow glows.
- **Stack Trace Input:** Monospaced `13px`, background `#FAFAF9`, with an integrated line number gutter.

### Checkboxes & Radio Controls
- **Size:** `16x16px` with `4px` radius (checkbox) or circular (radio).
- **Active State:** Background `#18181B` with crisp white checkmark / center dot. Focus ring `2px` offset.

### Cards & Panels
- **Standard Panel:** `#FFFFFF` background, `1px solid #E7E5E4`, `12px` radius, padding `24px`.
- **Interactive Card:** On hover, border transitions to `#D6D3D1` with subtle vertical elevation (`translateY(-2px)`) and `--shadow-md` reveal. Embedded utility icons shift from `#71717A` to `#18181B`.
